SIGMOD/PODS logo concepts

Four proposals for a joint SIGMOD/PODS mark, starting from the oval used on the 2024 and 2025 sites. Each one is a single file that stays the same every year. Each year adds only its year and city next to it, as in the "2027 header" column.

Colors come from sigmod.org: SIGMOD navy #1f4fa3 and its rust accent #9a3412, used here for PODS.

Before any of these is final

  • Agree on the concept with the SIGMOD and PODS executive committees, since the mark represents both.
  • Convert the lettering to outlines so the files look the same on every computer. The drafts use live text in Inter and Newsreader.
  • Export a favicon set (16, 32 and 180 px) and a one-color version for print.
