A reusable SIGMOD/PODS conference site

Round 3 (option E) keeps the 2026.sigmod.org menu structure and comes with four SIGMOD/PODS logo concepts. Round 2 (option D) follows the feedback on round 1: a more predictable, classic structure that is easy to update and works on phones. Round 1 (options A–C) explores three design directions rendering the same real SIGMOD/PODS 2027 content. All three use the type and colors of the redesigned sigmod.org (Inter + Newsreader, SIGMOD navy). Only the accent color changes each year.

Option E · round 32026 structure, modernised

The final 2026 site's structure kept as it was: the same eight menu groups (Welcome, Program, Special Events, SIGMOD Program, PODS Program on the left; Participant Information, Organization, Calls for Submissions on the right), the same page names, and a banner with the content in the middle. It has modern type, an "Upcoming dates" box, and a "new" marker for recent pages.

Editing works the same way as option D: one heritage/content/site.yml and one Markdown file per page. On laptops both menus stack on the left; on phones they fold into a Menu button.

The header uses the refined oval logo. Add ?logo=cylinder, overlap or wordmark to any page to try the other concepts.

Option D · round 2Classic, editable

Every page has the same skeleton: masthead, a five-item menu (Home, Attend, Program, Submit, Organization), the current section's pages on the left, content, footer. Only the homepage adds a banner and an "Upcoming dates" box.

Updating it means editing text files. Page text is Markdown in classic/content/pages/. Dates, menus, news and chairs are in one classic/content/site.yml. Change a date there and the homepage box, the Important dates page and the call pages all update. A menu entry without a page shows "coming soon" instead of a broken link.

Use the switch at the bottom right to try two section-menu layouts: a left sidebar or tabs under the title.

Round 1

Option ASociety

A close sibling of sigmod.org. Top navigation with one mega-menu, a calm hero, deadline cards, news, keynotes, organizers and sponsors. Dates are shown as tables, one column per submission round.

Good
  • Safest, most "official" look
  • Matches sigmod.org
  • Easy for any web chair to maintain
Watch
  • Generic; less sense of place
  • Long inner pages need the TOC

Option BHandbook

The familiar three-column SIGMOD layout, rebuilt. The left navigation is always visible and searchable (press /). The right rail shows a deadline countdown, upcoming dates and quick links on every page.

Good
  • Continuity with 2024–2027 sites
  • Every page one click away
  • Best for content-heavy years
Watch
  • Denser; three columns need a wide screen
  • Least distinctive
HomeDates

Option CSeason

Built around the conference year and the visitor. The homepage changes with the phase of the year (submissions, conference week, after). It has a visual deadline timeline and entry points for authors, attendees and sponsors. Dates are shown as a filterable month-by-month agenda.

Good
  • Fastest path to "what do I need now"
  • Most modern; strongest identity
  • Fits the rolling multi-round deadlines
Watch
  • Boldest of the three (dark hero)
  • Phase logic needs a dated data file

Shared across all options

  • Four top-level sections instead of five parallel menus: Attend, Program, Submit, About. PODS becomes a track label inside each section, so the SIGMOD and PODS menu trees are no longer duplicated.
  • One data file per year. Dates, chairs, news, keynotes and navigation all live in content.js. The "next deadline", "N days left", struck-through past dates and the .ics calendar export are all computed from it, so nothing needs editing by hand when a deadline passes.
  • Time travel for review: add ?today=YYYY-MM-DD to any page to see it on that date.
  • Mobile-first layout, accessible landmarks, no framework, no build step.
