SIGMOD/PODS conference site: five proposals

Five designs for a reusable SIGMOD/PODS conference website. All five are static pages built from the same content (SIGMOD/PODS 2028 in Seoul) and follow the menu structure of 2026.sigmod.org. Changing the design does not change any text: each year edits one settings file and a folder of page files.

The proposals

Open one and resize the window, or open it on a phone. Each card shows the desktop and phone homepage. Proposal 1 is the current favourite; the others show different ways to reach the same pages.

What they share

One place to edit

Dates, menus, news, chairs and sponsors are in content/site.yml. Each page is a Markdown file in content/pages/; the footer of every page shows which file it is.

Static and light

Plain HTML pages with one stylesheet and one 2 KB script. No framework runs in the browser, so pages load fast on conference Wi-Fi.

Dates that keep themselves current

Past dates turn grey and the next deadline is highlighted. The site rebuilds daily, and the small script also checks in the browser. Add ?today=2028-06-20 to any page to preview another day.

Pages before they exist

Every menu item from the 2026 structure is listed from day one. Items whose page file does not exist yet show a short "coming soon" note.

Published by GitHub

Pushing to main rebuilds the site with GitHub Pages. Editors can change a page on github.com without installing anything.

Per-year identity

Each year sets its own accent color, banner photo and city. The SIGMOD/PODS and ACM logos stay the same, in the footer as on past sites (new logo concepts are in explorations/logos).

Earlier rounds

The first three rounds of this exploration (options A–E and the logo concepts) are kept in explorations/. They render in the browser and are not part of the template.

SIGMOD/PODS 2028 details as of November 2026. Submission deadlines are placeholders (the 2027 dates moved forward one year), the banner is a placeholder illustration, and sponsor logos are not shown.
